# 🐱 CatCloud – Random Cat Image Generator

Discover adorable cats from around the world with **CatCloud**, a fun and interactive web application that brings a little happiness to your day!

CatCloud fetches random cat images using The Cat API and allows users to like their favourite cats, save them for later, and download images.

---

## ✨ Features

- 🐾 **Random Cat Generator** – Discover a new adorable cat with every click.
- ❤️ **Like Your Favourite Cats** – Save cats you love.
- ⭐ **Favourite Collection** – View your saved cat images.
- 📥 **Download Images** – Download your favourite cat pictures.
- 💾 **Local Storage** – Your favourite cats remain saved even after refreshing the page.
- 🎨 **Aesthetic UI** – Beautiful pastel-themed interface.
- 📱 **Responsive Design** – Supports different screen sizes.

## 🚀 Installation & Setup

Follow these steps to run CatCloud locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd CatCloud
```

### 3. Run the Application

Using Python:

```bash
python -m http.server 5500
```

### 4. Open in Browser

Visit:

```text
http://localhost:5500
```

Alternatively, open `index.html` using the VS Code Live Server extension.

---

## 🌐 API Integration

CatCloud uses **The Cat API** to fetch random cat images.

API Endpoint:

```text
https://api.thecatapi.com/v1/images/search
```

The application dynamically retrieves cat images without requiring users to upload images manually.

API Documentation: https://docs.thecatapi.com/

---

## 💡 How It Works

1. Open CatCloud in your browser.
2. A random cat image appears automatically.
3. Click **Another Cat** to discover more cats.
4. Click **Like** to save your favourite cat.
5. View your saved images in the Favourites section.
6. Click **Download** to download the displayed cat image.
